# ERP-Landing

مركز تحميل UltimateERP للمكتب وتطبيق المندوبين على Android، بالعربية وRTL.

## التطوير

موقع ثابت بدون مكتبات تشغيل أو طلبات API عند فتح الصفحة. الخطوط محلية بترخيص SIL OFL.

```sh
npm run build
npm run check
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

- `releases.json`: مصدر أرقام الإصدارات وأحجام الملفات وروابطها وبصماتها.
- `src/index.html`: قالب الصفحة. يُنتج البناء `index.html` في الجذر ونسخة النشر داخل `dist/`؛ لا تعدّل الملف المولّد مباشرة.
- `styles.css`: الهوية والأجهزة التوضيحية والتجاوب وتقليل الحركة.
- `site.js`: نسخ بصمة الملف مع رسالة حالة وإمكانية النسخ اليدوي عند الرفض. روابط التنزيل والأسئلة تعمل دون JavaScript.
- `vercel.json`: بناء الموقع الثابت ورؤوس الاستجابة. يظل النشر في مشروع Vercel المتصل بالمستودع.

## مصدر التحميل

الملفات الفعلية منشورة في `Mohamedz4K/Ultimate-ERP-Download`؛ صفحة `ERP-Landing` تشير إليها مباشرة. وجود الملفات تحت الوسم `v2.0.0` لا يغيّر رقم إصدار كل ملف: المكتب 4.0.0 والهاتف 1.0.20 بناء 26. لا تكرر رفعها داخل مستودع الصفحة.

## تحديث الملفات

1. أنشئ إصدار GitHub يحتوي الملفات الفعلية، ولا تستخدم ملف APK مؤقتًا أو تضع ملفات EXE/APK داخل Git.
2. تحقق من الإصدار والحجم وSHA-256. حدّث `releases.json` ثم شغّل البناء والفحص.
3. راجع الصفحة على شاشة كمبيوتر وهاتف، ومع تعطيل JavaScript وتقليل الحركة، ثم تحقق من روابط التنزيل قبل النشر.

الإصدار الحالي للتجهيز والتجربة قبل التعميم؛ لا تمثل الصفحة شهادة اختبار على أجهزة العملاء. احتفظ ببيانات المستخدمين أثناء التحديث، ولا تضمّن قواعد بيانات أو سجلات تشغيل أو بيانات اعتماد في الموقع أو الإصدار العام.
